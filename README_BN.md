# Video Downloader — সম্পূর্ণ প্রজেক্ট (ওয়েবসাইট + ব্যাকেন্ড)

এই ফোল্ডারে ওয়েবসাইট আর ব্যাকেন্ড দুটোই আছে। একটাই সার্ভিস হোস্ট করলে সবকিছু চালু হয়ে যাবে।
কোনো `npm install` লাগে না, কোনো প্যাকেজ নেই, শুধু Node.js (১৮ বা তার বেশি) লাগে।

## ফোল্ডারে কী আছে
- `server.js` — ব্যাকেন্ডের সব কাজ (RapidAPI-র সাথে কথা বলা, ফাইল নামানো, প্রগ্রেস, সীমা)
- `public/index.html` — আপনার ওয়েবসাইট (ইন্ট্রো, বাটন, সব অ্যানিমেশনসহ)
- `.env.example` — সেটিংসের নমুনা

## হোস্টিং (Render বা Railway)
1. ফোল্ডারটা GitHub-এ আপলোড করুন। (`.env` ফাইল কখনো আপলোড করবেন না, আপনার API কী ওখানে থাকবে।)
2. Render-এ **New → Web Service** বানান, রিপোজিটরি দিন।
   - Runtime: **Node**
   - Build Command: খালি রাখুন (বা `echo ok`)
   - Start Command: `node server.js`
3. **Environment Variables** পেজে এটা যোগ করুন (সবচেয়ে জরুরি ধাপ):
   - `RAPIDAPI_KEY` = আপনার RapidAPI key
4. Deploy শেষ হলে লিংক খুলুন। সাইট নিজে থেকেই ব্যাকেন্ডের সাথে জুড়ে যায়, কিছু এডিট করতে হয় না।
5. সার্ভার ঠিক আছে কি না দেখতে `আপনার-লিংক/health` খুলুন, `{"ok":true}` আসা উচিত।

নিজের কম্পিউটারে চালাতে: `.env.example` কপি করে `.env` নাম দিন, key বসান, তারপর `node server.js` দিন।

## API ঠিকমতো পড়া হচ্ছে কি না দেখা (গুরুত্বপূর্ণ)
এই API-র উত্তরের ফরম্যাট আমি নিজে চালিয়ে দেখতে পারিনি, তাই ব্যাকেন্ড বিভিন্ন ধরনের ফরম্যাট বুঝতে পারে এমনভাবে বানানো। হোস্ট করার পর একবার যাচাই করে নিন:
1. Environment Variables-এ `ADMIN_KEY` নামে একটা লম্বা র‍্যান্ডম লেখা দিন (যেমন `x8Kq2mZ9vLp4Rt7w`)।
2. `আপনার-লিংক/selftest?key=আপনার-ADMIN_KEY` খুলুন।
3. `counts` অংশে `videos` আর `audios` এর সংখ্যা ০ এর বেশি এবং `meta.title` ঠিক থাকলে সব ঠিক আছে।
4. কিছু ভুল দেখালে ওই পেজের লেখাটা কপি করে আমাকে পাঠান, আমি মিলিয়ে ঠিক করে দেব।

## খরচ ও সীমা (আপনার API কোটা বাঁচাতে)
- প্রতিটা ডাউনলোডে কয়েকটা API ক্রেডিট খরচ হয়: লিংক চেক ১, আর YouTube ডাউনলোডে আরও ২। একই লিংক ১০ মিনিটের মধ্যে আবার চেক করলে ক্রেডিট লাগে না।
- `DAILY_API_LIMIT` (ডিফল্ট ৪০০) ছুঁলে সার্ভার দিনের বাকি সময়ের জন্য API ডাকা বন্ধ রাখে। আপনার প্ল্যান অনুযায়ী এটা বদলান।
- একজন ব্যবহারকারী মিনিটে ১০টা চেক আর ৪টা ডাউনলোড করতে পারে, একসাথে ২টা। ফাইলের সীমা ৫০০ MB।
- ডাউনলোড করা ফাইল ১৫ মিনিট পর সার্ভার থেকে নিজে মুছে যায়।

## জেনে রাখুন
- **সাপোর্টেড:** YouTube, Facebook, Instagram, TikTok। **X (Twitter) এই API-তে নেই**, তাই ওই লিংকে সুন্দর করে "not supported" মেসেজ দেখায়।
- অডিও **MP3 নয়, M4A** ফরম্যাটে আসে (API সরাসরি এটাই দেয়, কনভার্ট করার সুবিধা নেই)।
- উঁচু কোয়ালিটির YouTube ভিডিওতে API সার্ভারে অডিও জোড়া লাগায়, তাই ৫–১০ সেকেন্ড বেশি লাগতে পারে। আপনার প্ল্যানে কয়টা কোয়ালিটি জোড়া লাগানো যায় সেটা প্ল্যানের ওপর নির্ভর করে। না গেলে সাইট নিজে থেকে শব্দসহ ছোট কোয়ালিটিতে নামিয়ে দেয়।
- ফ্রি হোস্টিং ঘুমিয়ে যেতে পারে, তখন প্রথম রিকোয়েস্টে দেরি হয়।
- **আপনার API key চ্যাটে শেয়ার হয়ে গেছে।** কাজ শেষে RapidAPI ড্যাশবোর্ডে গিয়ে নতুন key বানিয়ে পুরনোটা বাতিল করুন, আর নতুনটা শুধু হোস্টিংয়ের Environment Variables-এ বসান।
- অনেক প্ল্যাটফর্মের নিয়মে অনুমতি ছাড়া ডাউনলোড নিষিদ্ধ। সাইট সবার জন্য খুললে সেই অনুযায়ী Terms/DMCA পেজ রাখুন।

## ওয়েবসাইট আলাদা জায়গায় রাখতে চাইলে
`public/index.html` ফাইলে `var API="";` লাইনে ব্যাকেন্ডের লিংক বসান (যেমন `var API="https://আপনার-নাম.onrender.com";`)। তখন ব্যাকেন্ডে `ALLOWED_ORIGINS` সেটিংয়ে আপনার ওয়েবসাইটের ঠিকানা দিন।
